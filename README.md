## 📱 Mobile App (React Native + Expo Router)

The `mobile/` folder contains our cross-platform mobile app built with **React Native** and **Expo Router**.  
This is the template we’ll all work from.

### 🚀 Getting Started

1. **Install dependencies**
   ```bash
   cd mobile
   npm install

npx expo start --tunnel

mobile/
  app/              # Expo Router pages
  assets/           # Images, fonts
  package.json      # Dependencies
  ...

2. Run the app
   bash
   
   npx expo start --tunnel

Project Structure:
mobile/
   app/
   assets/
   package.json
   ...
   etc
